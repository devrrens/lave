# Design System — Barokah Jaya Fashion

## 1. Design Direction
Visual direction: **Soft Pink Boutique**

The experience should feel:
- Feminine
- Soft
- Warm
- Friendly
- Fresh
- Approachable
- Fashion-oriented
- Clean

Avoid:
- Childish visuals
- Neon colors
- Overly luxurious styling
- Corporate styling
- Generic marketplace layouts
- Overdecorated UI

## 2. Brand Personality
Soft + Feminine + Friendly + Modern.

The site should feel like a women's fashion boutique opened from an Instagram link.

## 3. Color System

Primary:
- Soft Pink: `#F6DDE5`
- Light Pink: `#FBECEF`
- Pink Accent: `#E8B7C6`

Background:
- Warm White: `#FFFCFA`
- Cream: `#FFF7F3`

Text:
- Primary: `#3D3436`
- Secondary: `#75696C`
- Muted: `#A99B9F`

Border:
- `#EDE2E5`

Semantic:
- Success: `#7A9B82`
- Warning: `#C79B55`
- Error: `#B86A72`

Pink is an accent, not the background for every component.

## 4. Typography

Heading:
- Playfair Display preferred
- Cormorant Garamond alternative

Body:
- Inter preferred
- DM Sans alternative

Use serif for:
- Hero
- Section headings
- Editorial storytelling

Use sans-serif for:
- Navigation
- Product names
- Prices
- Forms
- Buttons
- Admin

## 5. Typography Scale

Desktop:
- Hero: 64px
- H1: 48px
- H2: 36px
- H3: 24px
- Body: 16px
- Small: 14px
- Caption: 12px

Mobile:
- Hero: 40px
- H1: 32px
- H2: 28px
- H3: 20px
- Body: 15px
- Small: 13px

## 6. Layout
Max storefront width: 1200px.

Horizontal padding:
- Desktop: 32px
- Mobile: 20px

Section spacing:
- Desktop: 96px
- Mobile: 64px

Use generous whitespace.

## 7. Border Radius
- Main: 16px
- Product cards: 16px
- Buttons: pill / 9999px
- Inputs: 12px
- Feature cards: 24px

Do not round every element excessively.

## 8. Shadows
Use subtle shadows only.

Example:
`0 8px 30px rgba(61, 52, 54, 0.06)`

Prefer spacing, borders, and background contrast over heavy shadows.

## 9. Photography
Product photography is central.

Prefer:
- Natural lighting
- Bright backgrounds
- Warm tones
- Clean composition
- Soft shadows
- Feminine styling

Avoid:
- Heavy filters
- Dark backgrounds
- Excessive overlays
- Low-resolution images

Recommended product ratio: 4:5.

## 10. Homepage
Structure:
1. Navbar
2. Hero
3. Featured Collection
4. New Arrivals
5. Brand Story
6. Best Sellers
7. Editorial Banner
8. Testimonials
9. Store Information
10. Social Media
11. Footer

## 11. Hero
Editorial rather than generic e-commerce.

Suggested:
"BEAUTY IN EVERY DETAIL"

Supporting text:
"Discover feminine pieces made for your everyday moments."

CTA:
`Explore Collection`

Use soft pink/cream background and strong product photography.

## 12. Product Cards
Show:
- Image
- Name
- Price
- Optional discount
- Category/badge

Hover:
- Slight image scale
- Secondary image if available
- Quick action

Avoid aggressive animation.

## 13. Product Detail
Desktop:
Image/gallery on left, product information on right.

Information:
- Name
- Price
- Color
- Size
- Quantity
- Add to Cart
- WhatsApp order
- Description
- Size guide
- Care instructions

Mobile:
Image → Info → Variant → Quantity → CTA → Description.

## 14. Testimonials
Clean cards with:
- Rating
- Review
- Customer
- Verified label

If there are only a few testimonials, display them directly rather than forcing a carousel.

## 15. Brand Story
Use an asymmetric editorial layout:
Image + story.

It should feel like a boutique editorial section, not a generic corporate About block.

## 16. Mobile
Mobile is first-class.

Prioritize:
1. Photography
2. Product name
3. Price
4. Variant
5. Order CTA

Product grid: 2 columns.

Do not show tiny 3-4 column cards on mobile.

## 17. Admin Design
The admin is intentionally different.

Style:
- Clean
- Neutral
- Functional
- Easy to scan
- Practical

Use white/light gray surfaces and soft pink only as brand accent.

Do not make the admin look like the storefront.

## 18. Admin UX
Dashboard should emphasize:
- Revenue
- Orders
- Pending orders
- Low stock
- Best sellers

Tables should prioritize readability.

Forms should be compact and clear.

## 19. Buttons
Primary:
Soft pink filled button.

Secondary:
Outlined button.

Tertiary:
Text link.

CTAs must be obvious without being oversized.

## 20. Loading
Prefer skeletons over full-page spinners.

## 21. Empty States
Never leave blank screens.

Example:
"No products yet"
"Start adding your first product."
`Add Product`

## 22. Animations
Use subtle 150–300ms transitions.

Allowed:
- Fade
- Small slide
- Image scale
- Button hover
- Modal transition

Avoid:
- Excessive parallax
- Constant floating elements
- Large page transitions
- Distracting animations

## 23. Icons
Use Lucide Icons consistently.

Icons support the UI; they should not replace labels when meaning is ambiguous.

## 24. Design Principles
1. Photography comes first.
2. Whitespace is part of the design.
3. Soft does not mean childish.
4. Feminine does not mean everything needs to be pink.
5. Customer should always know what to do next.
6. Storefront sells the feeling.
7. Backoffice optimizes for speed and clarity.

## 25. Anti-AI-Slop Rules
Do not:
- Use generic gradients everywhere.
- Use random floating blobs.
- Use glassmorphism on every card.
- Add decorative sparkles without purpose.
- Use excessive rounded containers.
- Use generic SaaS dashboard patterns on storefront.
- Use giant text with no hierarchy.
- Add fake statistics.
- Add fake testimonials.
- Add fake business claims.
- Use irrelevant stock photos.
- Overuse animation.
- Use random pastel colors.

Every visual element must have a business, UX, or brand reason.
